# Independent human review worksheet

Use this worksheet before making broader semantic claims. Current challenge
labels are specification-aware author intent and have no independent human
adjudication. This file is a proposed review procedure, not completed evidence.

Give two reviewers case IDs and metadata without method outputs. For locally
acquired source records, apply the original reuse terms. Have each reviewer mark:
attack intent, benign documentation, ambiguous intent, surface applicability,
and whether the metadata alone permits a judgment. Require a brief rationale.
Preserve original labels; record reviewer labels separately with reviewer consent
and study revision. Resolve disagreement with a third reviewer or report it.
Do not remove ambiguous or missed cases after viewing method performance.

For real-host follow-up, predefine the trusted catalogue, selection task,
authorized server and arguments, agent/model/version, prompt, tool response,
benign utility criterion and actual instrumented side effect. Separate static
descriptor results from attack success and observe receipt/execution evidence.
Use a local sandbox and synthetic secrets. Do not score an authored projection
as a reproduced original exploit. Freeze the new protocol and test split before
adaptive red teaming, and preserve all unsuccessful attacks and false positives.
